# Scientific Review Report

> Post-Phase-5 scientific validation upgrade (2026-09-22). Strengthens the evaluation of the
> existing `random_forest-v1` orbital-only PHA-approximation experiment without changing it: no
> retraining of the primary model, no test-set changes, no leakage introduced, no fabricated
> numbers. Every value below is generated by `ml/diagnostics/*` and stored at
> `ml/diagnostics/output/*.json`; see those files for full precision and `docs/EXPERIMENTS.md`
> for the write-up each number is drawn from.

```
Scientific review:
PASS

Primary experiment:
UNCHANGED — ml/training, ml/preprocessing, ml/features, and docs/EXPERIMENTS.md's machine-
appended Experiment 1 log are byte-for-byte the same as before this review. `random_forest-v1`
remains the served default (validation PR-AUC 0.183, test PR-AUC 0.146).

Distribution shift:
FINDINGS — quantified, not just asserted. PHA prevalence falls 7.52% (train) -> 1.95%
(validation) -> 1.28% (test). Orbit-class composition shifts materially (e.g. Apollo prevalence
11.48% -> 3.05% -> 1.87%). A train-vs-test Kolmogorov-Smirnov test rejects "same distribution"
(p < 1e-6) for 6 of 7 raw orbital features; argument_of_perihelion_deg is the one exception
(p=0.283). Root CAUSE of the shift is INCONCLUSIVE from this dataset (no discovery-survey
completeness data available).

Subgroup evaluation:
RESULT — only the Apollo orbital class has enough positives (>=10) to evaluate in both
validation and test; its metrics (test PR-AUC 0.166, ROC-AUC 0.876) closely track the overall
model. Amor, Aten and Atira are INSUFFICIENT SAMPLE in both splits — no claim is made about them.

Calibration:
RESULT — NOT calibrated. random_forest-v1's Brier score on validation (0.0234) is worse than the
no-skill baseline (0.0191); the model is overconfident in its highest-scoring decile (mean
predicted 27.9%, observed frequency 13.0%). The API's `probability` field is documented as an
uncalibrated model score, not a calibrated probability (docs/API_CONTRACT.md,
docs/MODEL_CARD.md, frontend "Model Score" labeling).

Definition reconstruction:
RESULT — near-trivial once the label-defining variables are visible. Test PR-AUC rises from the
primary experiment's 0.146 (random forest, orbital-only) to 0.992 (random forest, + H/MOID) and
from 0.152 to 0.997 (XGBoost); even plain logistic regression rises from 0.052 to 0.736. These
are diagnostic-only artifacts under ml/diagnostics/artifacts/ (isolated from ml/artifacts/ and
from `python -m app.cli sync-models`) — never used for production, default-model selection, or
the /predict API (see tests/ml/test_diagnostics.py for the isolation guarantees).

Apophis:
RESULT — real, JPL-flagged PHA (H=19.09, Earth MOID 0.000108 au, Aten class). random_forest-v1
scores it 0.1763, below the 0.2703 decision threshold: a false negative, consistent with the
model's measured 39% test recall. One object; not a validation of overall performance.

Model status:
EXPERIMENTAL (unchanged — all six primary models and all diagnostic-only models remain
`experimental`/`diagnostic`; nothing was promoted).

Scientific limitations:
- Output is a ranking score, not a demonstrated probability (Calibration diagnostic above).
- Subgroup performance is measurable for one of four orbital classes only.
- The cause of train/test distribution shift remains unknown (INCONCLUSIVE), only its existence
  and magnitude are established.
- The primary model's weak performance is now directly attributable and quantified: it is
  solving a strictly harder task than definition-reconstruction, which is separately measured.
- Test set remains small (64 positives); all six primary models are statistically
  indistinguishable on test (unchanged finding from before this review).

Recommended future work:
- If a calibrated probability is ever needed, fit an explicit calibration step (e.g. isotonic or
  Platt scaling) on a held-out calibration split created for that purpose, and re-run the
  Experiment 3 diagnostic to confirm it, before changing any UI/API language back to
  "probability."
- Investigate discovery-survey completeness data (per-year magnitude limits, active surveys) if
  a future dataset snapshot or external source could explain the distribution-shift root cause
  currently marked INCONCLUSIVE.
- If Aten/Amor/Atira subgroup performance matters for a future use case, it would need either a
  much larger dataset snapshot or targeted data collection; do not report point metrics for them
  from the current sample sizes.
```

## Reproducing every number above

```bash
.venv/Scripts/python.exe -m ml.diagnostics.distribution_shift
.venv/Scripts/python.exe -m ml.diagnostics.subgroup
.venv/Scripts/python.exe -m ml.diagnostics.calibration
.venv/Scripts/python.exe -m ml.diagnostics.case_study
.venv/Scripts/python.exe -m ml.diagnostics.definition_reconstruction
```

Each command overwrites its corresponding file under `ml/diagnostics/output/`. All five ran
successfully against dataset `jpl-sbdb-neo-20260921-c34b5103` on 2026-09-22 using the pinned
environment in `.venv` (scikit-learn 1.9.1, xgboost 3.4.1, numpy 2.5.3, pandas 3.0.6, matching
the versions the production artifacts were trained with — verify with a mismatched environment
before trusting different numbers; see `tests/ml/test_diagnostics.py` for automated coverage.
