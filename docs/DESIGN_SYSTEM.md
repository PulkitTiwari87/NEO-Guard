# Design System

> **Status: PLANNED — The design will be implemented in Phase 3 using Stitch.**

## Design Direction

The NEO-Guard frontend should feel:

- **Scientific** — data-driven, precise, trustworthy
- **Premium** — polished, refined, professional
- **Minimal** — clean, uncluttered, purposeful
- **Precise** — exact typography, careful alignment
- **Modern** — contemporary patterns and interactions
- **Data-focused** — information density where appropriate
- **Calm** — restrained colour palette, no visual noise
- **Highly readable** — excellent legibility at all sizes

## Apple-Inspired Principles

The following principles guide the visual language (without copying Apple's proprietary UI):

- **Strong typography** — clear hierarchy using weight, size, and spacing
- **Whitespace** — generous margins and padding for breathing room
- **Hierarchy** — clear visual priority from primary to tertiary content
- **Subtle depth** — light shadows, layering, elevation
- **Restrained visual language** — limited colour palette, purposeful accents
- **Smooth transitions** — polished micro-animations on state changes
- **Meaningful animation** — motion that communicates, not decorates
- **Accessibility** — WCAG-compliant contrast, keyboard navigation, screen reader support

## Colour Direction

- Dark/light mode support
- Neutral base (greys, near-whites, near-blacks)
- Accent colour for interactive elements and data highlights
- Semantic colours for status (hazardous = warm, safe = cool)

## Typography Direction

- System font stack or a clean sans-serif (e.g., Inter, SF Pro-like)
- Clear size scale with consistent line heights
- Monospace for data values and codes

## Component Philosophy

- Small, focused, composable components
- Consistent spacing and sizing tokens
- Responsive from mobile to large desktop

> The actual design system will be generated by Stitch during Phase 3.
